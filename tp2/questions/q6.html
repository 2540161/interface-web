Question 6 - Appels API avec fetch et async/await

Recettes depuis une API

    Travail à réaliser

    • Complétez chargerRecettes() pour charger trois recettes depuis https://dummyjson.com/recipes?limit=3.
    • Le bouton Charger déclenche cette fonction.
    • Affichez un message pendant le chargement.
    • Affichez chaque recette dans un <li> de #recettes, avec son nom, sa durée et sa cuisine.
    • Un nouveau chargement remplace le contenu précédent.
    • En cas d'erreur réseau ou HTTP, affichez un message clair dans la page.

    Contraintes

    Utilisez fetch(), async/await et try/catch. Vérifiez response.ok. Les recettes doivent être ajoutées avec les méthodes du DOM.

    Format d'affichage

    Nom de la recette - X min - Type de cuisine

    Bonus - Effet de chargement

    Utilisez la classe CSS loading pour ajouter un effet visuel au message de chargement. Ce bonus est facultatif.
