Travail pratique 2 - JavaScript

Complétez les six fichiers JavaScript du dossier scripts/.

Consultez le README pour l'installation et les commandes de tests Cypress.

Questions

  1. Question 1 - Variables, types et expressions Convertisseur de température.
  2. Question 2 - Fonctions anonymes et fléchées Addition et multiplication.
  3. Question 3 - Objets et tableaux Affichage de listes de jeux filtrées.
  4. Question 4 - Manipulation du DOM Navigation, insertion, clonage et suppression.
  5. Question 5 - Gestion du temps Compteur avec démarrage et arrêt.
  6. Question 6 - Appels API Chargement de recettes avec fetch et async/await.

Travail

  • Modifiez seulement les fichiers scripts/q1.js à scripts/q6.js.
  • Vérifiez les résultats dans le navigateur.
  • Lancez npm test ou la commande de la question, comme npm run test:q1.
