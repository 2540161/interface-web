# Atelier 1 — Pratique HTML

Les consignes détaillées se trouvent sur la page de l'atelier dans le site du cours. Les numéros inscrits dans les commentaires des fichiers correspondent aux numéros affichés sur cette page.

## Travail demandé

1. Ouvrez `index.html` dans le navigateur.
2. Complétez les sections marquées `À COMPLÉTER`.
3. Modifiez seulement le HTML; n'ajoutez ni CSS ni JavaScript.
4. Respectez l'indentation et la structure déjà en place.
5. Testez les liens et les formulaires dans le navigateur.
6. Validez vos pages avec le [validateur HTML du W3C](https://validator.w3.org/).

Si vous ne savez plus quelle balise ou quel attribut utiliser, consultez d'abord les notes du module 2. Le solutionnaire peut ensuite servir à vérifier votre travail.
